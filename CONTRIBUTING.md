# Contributing

RepoAccord is pre-alpha. Changes should stay within the documented project scope.

- Set up the project with `uv sync`.
- Run `uv run ruff check .`, `uv run ruff format --check .`, and `uv run pytest -q`.
- Use descriptive branch names; examples include `feat/...`, `fix/...`, `docs/...`, and `chore/...`.
- Use a plain commit subject with no trailers.
